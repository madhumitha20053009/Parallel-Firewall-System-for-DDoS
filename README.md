# Parallel-Firewall-System-for-DDoS
Parallel Firewall System for DDoS Detection and Mitigation

Machine Learning – Attack detection
Parallel Processing – Simultaneous traffic analysis
Flask – Web application development
HTML, CSS, JavaScript – Frontend development
Wireshark / Scapy – Network traffic analysis

Project Objective:

To develop an efficient parallel firewall system that detects and prevents DDoS attacks using concurrent traffic analysis, thereby improving network security, reducing latency, and ensuring service availability.

Key Features:

Real-time network traffic monitoring
DDoS attack detection
Parallel packet processing
Malicious IP address blocking
Traffic filtering and classification
Firewall rule management
Network security report generation
